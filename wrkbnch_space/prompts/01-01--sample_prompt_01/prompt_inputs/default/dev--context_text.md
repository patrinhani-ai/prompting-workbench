## Sample context to be added to the prompt execution environment.

This context can include relevant information, data, or background details that the LLM might need to generate accurate and context-aware responses.
It can be used to set the stage for the prompt, ensuring that the LLM has all the necessary information to understand the task at hand.
For example, if the prompt is related to a specific domain or topic, the context can provide definitions, explanations, or examples related to that domain.
